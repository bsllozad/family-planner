# F05 — XP, niveles y rachas

**Estado:** Borrador

## F05-US01 — Consultar XP

Como niño quiero distinguir mis puntos gastables de mi progreso permanente.

### Criterios de aceptación

- La interfaz muestra XP disponible y XP histórico.
- Completar una misión incrementa ambos valores según el XP concedido.
- Canjes y penalizaciones reducen solo el XP disponible.
- Cada modificación queda registrada en un libro mayor.

## F05-US02 — Subir de nivel

Como niño quiero subir de nivel para conservar una sensación permanente de
progreso.

### Criterios de aceptación

- Rookie comienza en 0 XP histórico.
- Explorer se desbloquea en 500 XP.
- Hero se desbloquea en 1.500 XP.
- Champion se desbloquea en 3.500 XP.
- Gastar XP nunca reduce el nivel.
- Al alcanzar un nivel se muestra una celebración y sus desbloqueos.

## F05-US03 — Mantener una racha

Como niño quiero mantener una racha completando mis responsabilidades diarias.

### Criterios de aceptación

- El día cuenta si se completan todas las misiones obligatorias programadas.
- Las misiones opcionales no afectan la racha.
- Un día sin misiones obligatorias no rompe la racha.
- La vista muestra racha actual y mejor racha.
