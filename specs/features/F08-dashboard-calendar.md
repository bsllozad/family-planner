# F08 — Dashboard y calendario

**Estado:** Borrador

## F08-US01 — Dashboard infantil

Como niño quiero ver mis misiones y progreso en una pantalla atractiva.

### Criterios de aceptación

- Muestra avatar, nivel, XP disponible, racha y progreso al siguiente nivel.
- Muestra XP posible hoy y XP completado.
- Separa responsabilidades obligatorias de misiones extra.
- Funciona correctamente en celulares y computadora.

## F08-US02 — Dashboard administrativo

Como padre quiero ver rápidamente el estado de todos los niños.

### Criterios de aceptación

- Muestra resumen semanal por niño.
- Muestra solicitudes de canje pendientes.
- Muestra misiones omitidas, penalizadas y justificadas.
- Ofrece accesos para crear misiones, recompensas y correcciones.

## F08-US03 — Calendario

Como miembro de la familia quiero consultar el historial por fecha.

### Criterios de aceptación

- Distingue días completos, parciales, pendientes y sin misiones.
- El niño solo ve su calendario.
- El padre puede cambiar entre todos los perfiles.
- Las fechas se calculan con la zona horaria familiar.
