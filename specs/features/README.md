## Convenciones

- Cada historia usa el formato `Fnn-USnn`.
- Los criterios de aceptación usan Given/When/Then.
- Una feature está terminada cuando cumple sus criterios, pruebas y reglas de
  seguridad.
- Los recorridos que modifican XP deben probarse también en el servidor o base
  de datos, no únicamente en la interfaz.
