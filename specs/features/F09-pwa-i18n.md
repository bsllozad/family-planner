# F09 — PWA, idiomas y accesibilidad

**Estado:** Borrador

## F09-US01 — Instalar la aplicación

Como miembro de la familia quiero instalar la aplicación para abrirla como una
app desde mi dispositivo.

### Criterios de aceptación

- La aplicación incluye manifest, iconos y modo standalone.
- Es instalable en navegadores compatibles.
- El shell y la última información sincronizada pueden consultarse offline.
- Las operaciones de XP muestran que requieren conexión.

## F09-US02 — Elegir idioma

Como usuario quiero elegir español o inglés para entender toda la experiencia.

### Criterios de aceptación

- Cada usuario puede guardar su idioma.
- Navegación, validaciones y estados principales están traducidos.
- Cambiar idioma no cambia la preferencia de otros perfiles.
- Los títulos familiares permiten contenido en ambos idiomas.

## F09-US03 — Usar una interfaz accesible

Como usuario quiero interactuar con la aplicación independientemente del
dispositivo o forma de navegación.

### Criterios de aceptación

- Los controles tienen etiquetas accesibles y foco visible.
- El color no es el único medio para comunicar estados.
- Los objetivos táctiles son adecuados para niños y móviles.
- Las animaciones respetan la preferencia de movimiento reducido.
- Los recorridos principales funcionan con teclado.
