# F07 — Avatares e insignias

**Estado:** Borrador

## F07-US01 — Personalizar avatar

Como niño quiero personalizar mi personaje con elementos desbloqueados.

### Criterios de aceptación

- Cada perfil infantil comienza con un avatar básico.
- El catálogo incluye ropa, mascotas, fondos y accesorios.
- Solo se pueden equipar elementos desbloqueados.
- La selección se conserva entre dispositivos.

## F07-US02 — Desbloquear elementos

Como niño quiero obtener elementos al progresar para sentir que mi avatar
evoluciona.

### Criterios de aceptación

- Niveles e insignias pueden desbloquear elementos.
- Cada elemento se desbloquea una sola vez.
- Gastar XP no vuelve a bloquear elementos.
- El desbloqueo muestra una celebración apropiada para edades de 9 y 12 años.

## F07-US03 — Ganar insignias

Como niño quiero obtener insignias por hitos especiales.

### Criterios de aceptación

- El MVP incluye primera misión, racha de 7 días, 100 XP, 500 XP, 1.000 XP y
  semana completa.
- Las insignias se conceden automáticamente y una sola vez.
- El perfil muestra las obtenidas y las próximas alcanzables.
