# Dashboard y calendario

**Estado:** Borrador

## Vista del niño

- `DAS-001`: Tarjeta principal “Misión de hoy” con XP posible y completado.
- `DAS-002`: Barra de progreso al siguiente nivel.
- `DAS-003`: XP disponible, nivel y racha actual.
- `DAS-004`: Próximas recompensas alcanzables.
- `DAS-005`: Celebración visual breve al completar una misión, subir de nivel o
  desbloquear un elemento.
- `DAS-006`: Calendario con días completos, parciales y pendientes.
- `DAS-012`: Avatar actual, elementos desbloqueados y accesos de
  personalización.
- `DAS-013`: Separación visual entre misiones obligatorias y misiones extra.
- `DAS-015`: Las misiones atrasadas muestran su XP reducido y cualquier
  penalización aplicada.
- `DAS-016`: Los viernes se muestra la opción de conversión a dinero cuando el
  saldo alcanza el mínimo.

## Vista del padre

- `DAS-007`: Resumen de cada niño.
- `DAS-008`: Bandeja de solicitudes de canje pendientes.
- `DAS-009`: Progreso de la semana y misiones omitidas.
- `DAS-010`: Accesos rápidos para crear misión y recompensa.
- `DAS-011`: Ranking semanal opcional.
- `DAS-014`: Historial para corregir una misión marcada por error.
- `DAS-017`: Control para justificar o perdonar una misión obligatoria atrasada.

## Estadísticas del MVP

- XP ganado por semana.
- Misiones completadas frente a asignadas.
- Racha actual y mejor racha.
- Distribución por categoría.
